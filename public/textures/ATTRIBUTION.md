# Texture attribution

All surface maps in this directory are real photographic/mosaic maps of the
actual bodies, in equirectangular projection, from the sources below.

## Solar System Scope texture pack — CC BY 4.0

`sun.jpg`, `mercury.jpg`, `venus.jpg` (cloud layer), `mars.jpg`,
`jupiter.jpg`, `saturn.jpg`, `saturn_ring.png`, `uranus.jpg`, `neptune.jpg`

Textures by [Solar System Scope](https://www.solarsystemscope.com/textures/),
licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Based on NASA elevation and imagery data.

## NASA — public domain

- `earth.jpg` — NASA Visible Earth, Blue Marble: Land Surface, Ocean Color
  and Sea Ice (MODIS composite).
- `moon.jpg` — NASA LRO, LROC Wide Angle Camera global mosaic.
- `io.jpg`, `europa.jpg`, `ganymede.jpg`, `callisto.jpg` — NASA
  Galileo/Voyager global mosaics.
- `mimas.jpg`, `enceladus.jpg`, `tethys.jpg`, `dione.jpg`, `rhea.jpg`,
  `titan.jpg`, `iapetus.jpg` — NASA/JPL/Space Science Institute Cassini
  global mosaics (Titan: ISS global map).
- `phobos.jpg`, `deimos.jpg` — NASA Viking Orbiter global mosaics.
- `miranda.jpg`, `ariel.jpg`, `umbriel.jpg`, `titania.jpg`, `oberon.jpg`,
  `triton.jpg` — NASA Voyager 2 global mosaics.
- `pluto.jpg`, `charon.jpg` — NASA/JHUAPL/SwRI New Horizons global mosaics.

The NASA mosaics were obtained via the
[NOAA Science On a Sphere](https://sos.noaa.gov/catalog/) dataset mirror.
NASA imagery is in the public domain; NASA does not endorse this project.

Pluto's small moons (Styx, Nix, Kerberos, Hydra) have never been resolved
beyond a few pixels, so no real surface map exists for them — they keep the
procedural look in the demo.
